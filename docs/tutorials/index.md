# Tutorials

Follow a workflow from start to finish. Start with the first three if you are new to chemical
drawings; the later tutorials include example files so you can compare your result.

## Start here

| Tutorial | You'll learn |
|---|---|
| [Reading a structure drawing](reading-structures.md) | what line ends, corners, labels and implicit hydrogens mean |
| [Your first molecule in five minutes](first-molecule.md) | ethanol drawn from scratch, saved and exported |
| [Show calculated stereo labels](stereochemistry.md) | when Penzene can calculate R/S and how to show it |

## Draw and share

| Tutorial | You'll make |
|---|---|
| [Caffeine from the keyboard](keyboard.md) | a structure drawn with hotkeys: one click, then twelve keys |
| [Coming from another editor](coming-from-another-editor.md) | a CDXML drawing edited with familiar hotkeys and saved for another editor |
| [Newman and Fischer projections](projections.md) | projection drawings and a Fischer mirror image with verified stereochemistry |
| [A reaction scheme](reaction-scheme.md) | an aspirin synthesis with reagents and conditions, exported as SVG and PDF |
| [A dataset of structures](dataset.md) | a grid of drugs and a descriptor table, from a `.smi` file |
| [Supporting information and descriptor tables](supporting-information.md) | copied properties, dataset CSVs and a clearly labelled predicted NMR line |
| [A publication figure](publication-figure.md) | a coloured structure in a journal style, at print size |
| [Figures in Word, PowerPoint and LaTeX](office-latex.md) | a vector picture, an editable Windows drawing object and a LaTeX figure |
| [Journal-ready export](journal-export.md) | checked physical sizes, fonts, vector output and 600 dpi figures |
